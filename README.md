# 🚗 Spare Fix – Car Spare Parts & Service Provider App

## 📖 Overview
Spare Fix is an Android-based mobile application designed to simplify the process of purchasing car spare parts. It provides a seamless digital platform where users can browse, compare, and purchase spare parts, along with accessing nearby service providers for installation and maintenance.

This project aims to eliminate the inefficiencies of traditional spare parts shopping by offering a centralized and user-friendly solution.

---

## 🎯 Objectives
- Provide an easy platform to buy car spare parts online
- Enable users to compare products and prices
- Offer secure payment and order tracking
- Connect users with nearby mechanics for installation services
- Improve customer experience with a smooth interface

---

## 🛠️ Technologies Used
- **Frontend:** Java (Android)
- **Backend:** MySQL
- **IDE:** Android Studio / Eclipse
- **Platform:** Android SDK

---

## ⚙️ Features

### 👤 User Module
- User Registration & Login
- Browse spare parts
- Add items to cart
- Secure checkout & payment
- Order tracking

### 🏪 Dealer Module
- Add spare parts
- Manage product listings
- View product details

### 🔧 Mechanic Module
- Register & Login
- View service requests
- Provide repair/installation services

---

## 🔄 System Workflow
1. User registers and logs in  
2. Browses spare parts  
3. Adds items to cart  
4. Completes payment  
5. Option to choose service provider  
6. Order confirmation  



## 🗄️ Database Design
The system uses a structured relational database including:
- Users Table
- Dealers Table
- Spare Parts Table
- Orders & Order Items
- Payments
- Mechanics
- Service Requests
